# MatlabWordle
A simple version of Wordle coded into Matlab


Downloading all function files and drivers is required.

Run the main game file, with all the drivers downloaded to the directory. It may change settings, placing your figures in a docked window view, 
rather than opening in a new window.

There is an error range as a program created on a Mac, the figure occasionally does not present itself on Windows, and certain Mac versions.

(It's a Year 1 University project lol, not a finished, professional project yet)
